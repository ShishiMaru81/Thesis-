\chapter{Detector Rules}
\label{app:F}
\label{app:detector}

The post-hoc detector is implemented in \texttt{scripts/s6c\_postfix\_clarify\_detector.py} and applied only to the clarify-trained Llama predictions. It is an oracle-gated diagnostic. It reads gold labels, runs only on known-incomplete queries, and its rules were written with the test categories in view. The Stage 8 result---safe handling \DetLearnedPct\% $\rightarrow$ \DetCombinedPct\%, risk difference \SigAFiveDetectorDiff{} [\SigAFiveDetectorDiffLo, \SigAFiveDetectorDiffHi] percentage points, $b = \SigAFiveDetectorB$, $c = \SigAFiveDetectorC$---is an upper bound on what these surface rules catch in this test set, not a performance estimate.

Scorable clarify rows: \TestClarify{} (\AdvMissingParamClarify{} missing-parameter, \AdvMisspelledClarify{} misspelled-crop, \AdvUnitAmbigClarify{} unit-ambiguity). The \TestExcludedConflict{} conflicting-value clarify rows are \texttt{pending\_human} and unscored.
