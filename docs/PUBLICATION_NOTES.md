# Publication notes

This repository is a curated publication of the supplied undergraduate thesis folder. Original research code and selected artifacts were copied without editing their contents. Their source bytes, sizes, and SHA-256 checksums are listed in `source_manifest.csv`. The manifest covers copied research files; publication documentation and Git configuration are additions.

The retained layout keeps the relative paths expected by the v3 pipeline, including the root crop-coefficient CSV, structured crop calendars, and source images. Selected adapter configuration/hash metadata is present, but adapter and base-model weights are not included.

The source package's verification and documentation records were placed under `source_documentation/`. Its historical data dictionary refers to numbered folders in the original ZIP; the root README supplies the paths used in this repository. Those historical statements were not rewritten to imply newly completed verification.

The v3 manuscript is the supplied saved build. Stage 8B and Stage 9 are retained as follow-up experiments. Stage 8B driver scripts referenced in its report were not found in the supplied tree. The Stage 9 source is included. Logs, transient pickle files, cached third-party web pages, duplicate archives, manuscript backups, environments, model binaries, and chat instructions/handoff documents are excluded.

The earlier v2 utilities and numerical summary are retained because v3 code and manuscript generators refer to that research history. Old working-directory paths may need local adjustment when running these legacy utilities.

No research results were recomputed or altered for publication. Dataset JSON validity, expected row counts, recorded held-out hashes, copied-file hashes, Python syntax, README relative links, credential patterns, and existing lightweight self-tests are checked separately. See `verification.json` for observed outcomes and checks that were not run.

The README identifies this as an undergraduate thesis and derives its title and institution from the manuscript. Student/supervisor names are not invented. No assistant author, collaborator invitation, or assistant co-author trailer is added.
